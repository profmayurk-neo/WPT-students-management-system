# Assignment 1 — Student Management System
Run: `npm install`, `npm start`, `npm run lint` from this folder.
Data has 10 students. The service covers listing, ID search, department/semester filtering, average marks, attendance below 75%, marks above 80 in every subject, sorting, add with duplicate-ID protection, update, delete, JSON parsing/serialization and validated file saving.
The WPT notes cover JSON, objects/arrays, Node.js file I/O, error handling and ESLint. A temporary file is written before rename to reduce partial-write risk.
